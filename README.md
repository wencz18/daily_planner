# Daily Planner（每日计划软件）

选题 2：制作一款每日计划软件，可以输入计划与时间自行排表。

## 运行环境

- Python 3.12（使用 Anaconda 创建的 `py_312` 隔离环境）
- 只依赖标准库 `tkinter` + `json`，**无需 pip 安装任何第三方库**

## 运行方法

方式一（命令行）：

```bash
conda activate py_312
cd /d D:\project\python\game
python game.py
```

方式二（PyCharm）：用 PyCharm 打开 `game` 文件夹，把解释器设为
`D:\anaconda\envs\py_312\python.exe`，右键 `game.py` → Run。

## 功能说明

| 功能 | 说明 |
| --- | --- |
| 新增计划 | 输入计划内容、开始时间（HH:MM）、预计时长（分钟）、优先级（高/中/低） |
| 自动排表 | 按开始时间升序自动排序，时间相同则优先级高的在前 |
| 冲突检测 | 相邻计划时间重叠时弹出提醒，也可点「检查冲突」手动检查 |
| 标记完成 | 选中一行后点「标记完成/取消」，或直接双击该行 |
| 删除 / 清空 | 支持删除选中项与一键清空，均有二次确认 |
| 数据持久化 | 自动保存到同目录 `plan_data.json`，下次打开自动加载 |
| 统计信息 | 底部状态栏显示计划条数、总时长、已完成数量 |

## 文件结构

game/
